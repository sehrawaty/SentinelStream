1Redis

Blocklist check

SISMEMBER blocklist:cards

A blocked card is marked declined and skips the detectors.

2Redis

Idempotency guard

SET idem:txn:{id} 1 NX EX 900

A repeated delivery is acknowledged and dropped.

3Redis

Update windows

ZREMRANGEBYSCORE · ZADD
GEOADD · EXPIRE

One pipelined round trip trims and updates five windows.

4Redis

Run four detectors

ZCARD · ZREVRANGE · GEODIST

The rules read the windows and produce a score from 0 to 100.

5MongoDB

Save transaction

bulkWrite, upsert on txnId

Buffered: 200 documents or 500 ms. Never one insert per transaction.

6MongoDB

Save alert

insertOne

Only when the score is above 0. Immediate, so the alert can be read the moment it is announced.

7Neo4j

Queue graph edges

UNWIND $batch … MERGE

Buffered: 100 edges or 500 ms. MERGE makes a replay harmless.

8Neo4j

Ring query

MATCH … *1..6

Only if fan-out fired. Background thread, 300 s cooldown per card.

9Redis

Publish

PUBLISH alerts:live

Relayed to the dashboard over a WebSocket.

10Redis

Acknowledge

XACK

Always last. A crash before this point means redelivery, not loss.

Steps 5, 7 and 8 never wait on disk or network: they hand work to a queue or a background thread. Step 6 is the one deliberate exception.
