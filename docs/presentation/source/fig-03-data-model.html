Sorted-set score is the timestamp, so a window is trimmed by score and counted in constant time.

Memory is bounded by TTLs, not by eviction: the policy is noeviction.

blocklist:cards is the one key with no TTL. It records an analyst's decision and must survive a restart.

Neo4j

Entities and how they connect

  • A transaction is an event, not a node. The relationship carries a count instead.
  • Four uniqueness constraints, each backed by an index, so the starting card is found by a seek.
  • Every write is a batched MERGE, so a replay increments a counter.
