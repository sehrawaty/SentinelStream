2. Neo4j resolves

One traversal from the flagged card

MATCH (seed)-[:USED_DEVICE|FROM_IP*1..6]-(m:Card)

Follows device and IP links up to six hops, then keeps only the devices and IPs that two or more of those cards share.

In SQL this is a recursive self-join of unknown depth.

returns
the ring
